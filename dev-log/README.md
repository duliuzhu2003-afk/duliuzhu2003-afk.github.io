# dev-log 开发日志

每天一个文件，命名 `YYYY-MM-DD.md`（如 2026-08-18.md）。

## 统一模板

```markdown
# YYYY-MM-DD 开发日志

## 当日计划
- [ ] 本次会话要做什么

## 完成事项
- 做了什么（含验证结果）

## 待办事项
- [ ] 遗留事项与下一阶段

## 下一步
- 下一次会话/阶段要做什么
```

## 记录机制

1. **CLAUDE.md 工作守则**：每次会话开始读当天日志、结束前更新（最可靠）
2. **每日定时任务**（21:47）：提醒更新当天日志。注意：仅在 Claude Code 打开时触发；每 7 天过期，AI 会检查续期
