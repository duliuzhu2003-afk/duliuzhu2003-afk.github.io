# 朱翰林建筑作品集 · 网站使用手册

这是一份**写给朱翰林本人**的手册：网站怎么打开、想改东西时怎么跟 AI 说、每张图对应哪个文件。不用看懂任何代码。

---

## 1. 怎么看网站

- **本地预览**：双击 `index.html` 即可打开（字体和图片都在本地，不需要联网）。
- 更推荐的预览方式：让 AI 运行 `node tools/serve.js 8080`，然后浏览器打开 http://localhost:8080/
- 右上角「中文 / EN」按钮切换中英文，英文模式下简历下载按钮也会换成英文简历。

## 3. 想改内容，怎么跟 AI 说

**永远不用自己动手改文件。** 打开 Claude Code，把下面任意一句复制粘贴（把【】里的内容换成你的）：

- 「把【浙东运河博物馆】的【剖面图】改大一点」
- 「把【城市综合体】里第【15】张图换成新图，新图在 朱翰林的建筑作品 文件夹里」
- 「【关于我】里加上一句：……」
- 「把【大学生活动中心】的年份改成【2022】」
- 「新增一个作品【××设计】，图片我已经放进素材文件夹了」
- 「把网站发布到网上」

**换新图时**：把新图放进 `朱翰林的建筑作品\各项目小标题配图\对应项目\对应小标题\`（或任何素材文件夹），再告诉 AI 换哪张。AI 会自动压缩、替换、更新对照表。

## 5. 给 AI 的素材建议

- 格式 JPG / PNG 都行；原图越大越清晰越好（长边 3000px 以上最好）；单张不超过 20MB
- 透明底 PNG 没关系，网站会自动铺上米白纸底
- 图纸上的字越小，越需要高清原图

## 6. 关于网站的技术说明（不需要懂，遇到问题给 AI 看）

- 纯静态网页：只有 HTML / CSS / JS 三种文件，双击就能看，不需要服务器、数据库
- 所有字体都已下载到 `fonts\` 文件夹，断网也能正常显示
- 原始素材文件夹 `朱翰林的建筑作品\` 是**只读**的，网站只用它的压缩副本，原件永不改动
- 图片压缩、裁剪等全部由 `tools\` 里的脚本处理，图片一律「完整不裁剪、等比例、保留原色」
