# 03 · 技术方案

## 1. 架构原则

- **纯静态**：HTML/CSS/JS 三件套，无框架、无构建、无 npm 依赖
- **目标环境＝验证环境**：双击 index.html（file:// 协议）即可完整预览
- **运行时零外部请求**：字体全部自托管，国内网络友好
- **内容写死在 HTML**：不用 fetch/JSON，file:// 与部署双兼容

## 2. file:// 三大禁区（绝对规避）

1. **禁 fetch/XHR 加载本地文件**（Chrome CORS 拦截）→ 数据全部内联 HTML
2. **禁 ES Module**（`<script type="module">` 被拦截）→ 用普通 `<script src="js/main.js">`，放 `</body>` 前
3. **禁 localStorage/Service Worker**（file:// 下受限）→ 全部不用

另：图片懒加载用原生 `loading="lazy"`；JS 不阻塞渲染。

## 4. 字体自托管方案

- `tools/fetch-fonts.sh` 一次性执行：以 Chrome UA 请求 Google Fonts CSS2 API
- 拉丁字体（Playfair 700/900、Lora 400/700/400i、Inter 400/600/700、JetBrains Mono 400/700）**只保留 latin 分片**
- Noto Serif SC（400/700/900）保留全部 unicode-range 分片声明（约 330 个文件；浏览器按需只下载页面用到的分片，首访 300~600KB）
- 生成 `css/fonts.css`（路径指向本地 fonts/，勿手改）
- 降级预案：从 --f-display/--f-serif 栈删掉 Noto 项即回系统宋体

## 5. 图片管线（tools/compress.ps1）

- 输入：`朱翰林的建筑作品/N.作品名/*.png`（只读，永不改动原件）
- **输出 1 完整版** `images/project-NN/NN.jpg`：长边 3000px、JPG q85、sRGB、≤500KB
- **输出 2 封面版** `images/project-NN/cover-NN.jpg`：居中裁剪 4:3、1200px、q85、≤200KB
- **铁律：先铺 #F9F9F7 底色再存 JPG**（透明 PNG 直接转 JPG 会变黑）
- 占位图：同脚本生成 halftone 半调纹理 JPG（<60KB）
- 实现：PowerShell + System.Drawing（本机已验证可用，无需安装）

## 6. 性能指标

- 首页完整加载 <2MB（含字体分片）；单图 ≤500KB；封面 ≤200KB
- 详情页下方图片 loading="lazy"
- 动画只用 transform/opacity（GPU 加速），不直接动画 box-shadow

## 7. 部署（阶段 8 与用户商定）

- 主选 GitHub Pages（gh CLI 操作）；国内不稳备选 Netlify（拖拽部署）/Gitee Pages
- 原始素材目录被 .gitignore 排除，永不进仓库（GitHub 单文件 >100MB 拒收）

## 8. 维护约定

- 版本管理：git，每阶段结束提交
- 每次换图/改字后同步更新 README「文件 ↔ FIG ↔ 内容」对照表
- 年份等动态元数据用 `data-year` 自动更新，不手写死
