# 01 · 需求说明

> 状态：2026-08-18 与用户确认 ✅

## 1. 网站用途

朱翰林的个人建筑作品集网站：展示建筑作品（效果图、立面图、平面图、剖面图等图片）＋ 个人基本信息与介绍。

## 2. 已确认决策（2026-08-18）

1. **结构**：首页（报纸头版风格）＋ 每个作品独立详情页（报纸文章风格）
2. **语言**：中英双语
3. **技术**：纯静态网页 HTML/CSS/JS，无框架无构建；双击 index.html 即可预览；可部署 GitHub Pages / Netlify
4. **设计风格**：Newsprint 报纸风（规范见 docs/02-设计规范.md）
5. **作品收录**：素材文件夹现有 6 个作品（24 张图），**阶段 4 开始前与用户确认是否全部收录**
6. **图片交互**：点击任何图片浮出完整大图（灯箱），可放大查看细节
7. **图片排版**：AI 自动裁剪生成 4:3 封面版用于首页卡片；详情页与灯箱用不裁剪的完整图

## 4. 收录规则

- 原图只读保留，网站只引用压缩副本（images/project-NN/）
- 新作品由用户放进素材文件夹，AI 按 docs/05 流程收录
- 首页/详情页文案、个人信息、联系方式为占位内容，阶段 7 与用户逐项定稿
- **项目编号与展示顺序（用户 2026-08-19 定稿）**：01 浙东运河博物馆设计 ｜ 02 大学生活动中心设计 ｜ 03 城市综合体设计 ｜ 04 多功能剧场设计 ｜ 05 高层建筑设计 ｜ 06 城市设计（与素材文件夹前缀数字无关：素材 1.城市综合体→网站 03、素材 3.浙东运河博物馆→网站 01，映射见 tools/crops-pNN.txt 的 proj 列）

## 5. 用户的工作方式要求

1. 分阶段小步推进，每阶段完成、验证后停下汇报，用户确认后再继续
2. dev-log/ 开发日志：自动记录每天完成事项与待办
3. docs/ 标准文档：需求、技术、设计规范、执行步骤
4. CLAUDE.md：指引标准文件路径与工作说明
5. 所有回复与选项使用中文
