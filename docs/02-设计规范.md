# 02 · 设计规范（Newsprint 报纸风）

> 施工标准：一切颜色、字体、间距、组件以本文为准，不即兴发挥。

## 1. 设计哲学

**"All the News That's Fit to Print."** 黄金报业时代的数字复刻：绝对清晰、层级分明、网格结构、锐利几何。

- **直角**：全部元素 0 圆角（全局 `* { border-radius: 0 !important }`）
- **高信息密度**：紧凑留白、共享边框、报纸分栏
- **字体戏剧性**：超大衬线标题（桌面最高 128px）＋ 小号高可读正文
- **可见结构**：网格线被庆祝而非隐藏，分栏边框明确
- **编辑权威感**：严肃、永恒、可信
- **纸质感**：点阵与细线纹理，克制不拟物
- **调性**：权威、智识、紧迫、永恒。永远米白纸面，**无暗色模式**

**红线**：红色禁止小字号正文；黑底红字仅 ≥48px 大数字；ticker 徽章用"红底白字"而非红字。

## 3. 字体

自托管 woff2（css/fonts.css 声明，运行时零外部请求）：

- 英文标题 **Playfair Display** 700/900；英文正文 **Lora** 400/700/400i
- UI 标签 **Inter** 400/600/700；数据 **JetBrains Mono** 400/700
- 中文标题与正文 **Noto Serif SC** 400/700/900（unicode-range 分片按需下载）
- 中文 UI 兜底：PingFang SC / Microsoft YaHei

**字体栈（单栈逐字符回退，汉字自动落到 Noto Serif SC，无需拆 span）：**

```css
--f-display: "Playfair Display", "Noto Serif SC", "Songti SC", serif;
--f-serif:   "Lora", "Noto Serif SC", "Songti SC", serif;
--f-sans:    "Inter", "PingFang SC", "Microsoft YaHei", sans-serif;
--f-mono:    "JetBrains Mono", ui-monospace, "Cascadia Mono", monospace;
```

## 4. 字号体系（clamp 响应式）

- `--fs-hero`: clamp(4rem, 9vw, 8rem) 64→128px；中文行高 1.05，英文 0.9
- `--fs-h2`: clamp(2.25rem, 3.4vw, 3rem) 36→48px，行高 0.95
- `--fs-h3`: clamp(1.5rem, 2vw, 1.875rem) 24→30px
- `--fs-body`: clamp(0.875rem, 1vw, 1.125rem) 14→18px，**中文行高 1.9**（英文 relaxed 1.625）
- `--fs-label`: 0.75rem（12px），全大写，字距 0.25em

## 5. 双语排版铁律

1. **标题永远中英分两行**：中文大号（Noto 900）＋ 英文小号全大写（Playfair 900，约为中文的 0.3 倍，tracking-tighter）——避免"中文压英文"的视觉冲突
2. 正文同栈自动切换；text-justify（中文 inter-ideograph）
3. **中文段落单栏**（中文无空格，多栏断行乱）；`columns: 2` 仅用于英文段落
4. 中文字重只用 400/700/900，900 仅标题
5. 标签含中文时汉字回落苹方/雅黑，数字仍用 JetBrains Mono（如「FIG. 1.1」）
6. 全局 `text-rendering: optimizeLegibility`；`font-display: swap`

## 6. 边框与圆角

- 圆角 0 无例外（全局强制）
- 标准 1px 实线墨黑；重大分隔 4px（`--bd-heavy`，如报头底、区块顶）
- **共享边框**（collapse 防双线）：容器 border-top/left，子项 border-right/bottom，行末列去 border-right
- 反转区块内线条用 --c-invert-line

## 7. 阴影与效果

- **扁平无柔影**：无模糊、无渐变、无内阴影
- 硬阴影悬停：`box-shadow: 4px 4px 0 0 #111` ＋ `translate(-2px,-2px)`（报纸剪报抬起感）

## 8. 纹理（纯 CSS，无图片文件）

1. **页面点阵背景**：4×4px SVG data-URI（`#` 必须转义 `%23`）
2. **.grid-lines**：3px 细线网格叠加（::before，pointer-events:none）
3. **.halftone**：16px 径向点阵半调占位
4. **.sep-stars**：✦✦✦ 装饰分隔（serif、letter-spacing 1em、上方 border-top 发丝线）

## 10. 组件规范

### 按钮 .btn（min-height 44px、全大写、字距 .25em、mono 12px、transition 200ms）

| 变体 | 常态 | 悬停 |
|---|---|---|
| .btn-primary | 黑底白字 | 反转：白底黑字黑边 |
| .btn-outline | 透明底＋黑描边 | 填充黑、白字 |
| .btn-ghost | 无边框 | 灰底（--c-hairline） |
| .btn-link | 纯文字 | 红色 2px 下划线（offset 4px） |

移动端按钮全宽（w-full），桌面自适应宽度。

### 卡片
- .card：1px 黑边 ＋ paper 底 ＋ p-6~p-8
- 交互卡：hover 硬阴影或 bg n100；内部图片悬停 sepia＋scale

### 图片
- .img-newsprint：默认灰度，悬停怀旧棕褐
- 首页卡片用 4:3 裁剪封面；详情页/灯箱**永远用不裁剪完整图**
- 每图配 FIG 图注「FIG. 1.1 — 中文说明 ENGLISH CAPTION」

### 图标
- 内联 SVG，stroke 1.5px，墨黑（反转区块白色）
- .icon-box：3rem×3rem 黑边盒 flex 居中，hover 黑白反转

### 表格 .table-mono
行 border-b；左标签灰 mono 全大写，右值墨黑。

### ticker 跑马灯
黑底白字，内容两份无缝循环（CSS keyframes `translateX(-50%)`，30s linear infinite），第二份 aria-hidden；hover 暂停；prefers-reduced-motion 停用动画。

### 灯箱
rgba(17,17,17,.92) 黑底覆盖层；mono 计数「03 / 12」；按钮 ≥44px 白描边；支持 ←/→ 切换、Esc 关闭、放大/还原、拖动画布、移动端双指缩放、点击遮罩关闭、焦点圈定与归还。

## 11. 强制特色元素（不可省）

1. **垂直网格分隔线**：同排内部 border-right 分栏，页面像报纸拼版
2. **drop cap 首字下沉**：关键段落首字（反转区块用红色）
3. **黑底 ticker**：红徽章＋白字滚动
4. **版元数据**：页眉「VOL. 1 | 日期 | NO. 01」；页脚「EDITION: VOL 1.0 | PRINTED IN BEIJING」；图片 FIG 编号
5. **text-justify 正文**（多栏仅英文）
6. **图片灰度 → 悬停 sepia**
7. **非对称布局**：8/4、5/7 分栏，禁用 50/50
8. **大写等宽标签**：导航、眉题、元数据
9. **至少一个黑底反转区块**：白色文字＋红色数字步骤

## 12. 布局

- 容器 .container：max-width 1280px、居中、px-4
- 12 列网格；区块纵向 py-16；间距 8px 体系（8/16/24/32/48/64）
- 页头 sticky z-40；覆盖层 z-50

## 13. 动效

- 一律 `transition 200ms ease-out`，机械利落，无弹跳缓动
- 悬停清单：按钮/图标黑白反转、卡片硬阴影、链接红下划线、图片 sepia＋scale、小元素 scale
- 灯箱淡入 200ms；ticker 30s 线性循环；动画只用 transform/opacity

## 14. 响应式

- 断点：**1024px**（8/4、5/7 → 12/12 单列；去 border-right 只留 border-b；侧栏不 sticky）、**768px**（标题走 clamp 下限、按钮全宽、汉堡菜单、取消多栏）
- 移动端保留：直角、高对比、单列网格、横线分隔、大写标签
- 触控目标 ≥44×44px

## 15. 无障碍

- 语义化 header/nav/main/section/footer；h1→h6 层级正确
- focus-visible：2px 墨黑环＋2px 偏移（反转区块改白环）
- 图标按钮 aria-label；图片 alt；ticker 第二份 aria-hidden
- 键盘：所有交互可达；灯箱焦点圈定；汉堡菜单 aria-expanded；关闭后焦点归还触发元素
